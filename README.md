# 栄養量計算補助ツール — GitHub Pages用

2026年9月26日配布版。点滴・食事・経腸栄養・ONSの合計、Na追加量の試算、モバイル下部の7項目表示を含みます。ビルドやAPIキー、サーバー設定は不要です。

## 最初に確認

この版にログイン機能はありません。通常のGitHub Pagesではサイトがインターネットに公開されます。リポジトリをPrivateにするだけで、サイト自体も非公開になるわけではありません。自分専用の非公開サイトが必要な場合は、この方法で公開しないでください。

配布物には患者情報や認証情報を含めていません。患者名・IDなどを入力しないでください。計算入力は保存・サーバー送信せず、編集した製品マスタと最近選んだ製品だけを端末のブラウザに保存します。GitHubには通常のページアクセスが発生し、出典リンクを開くと各外部サイトへ移動します。

## 公開方法（ブラウザだけで可能）

1. GitHubにログインし、新しいリポジトリを作成します。名前の例は `nutrition-calculator`。GitHub Freeで利用する場合はPublicリポジトリにします。既存の別サイトがあるリポジトリへの上書きは避けてください。
2. ZIPを解凍します。ZIPファイル自体ではなく、中身のファイルと `data` フォルダを、GitHubの **Add file → Upload files**（空リポジトリでは **uploading an existing file**）からアップロードし、**Commit changes** で保存します。
3. リポジトリの最上位に `index.html` があること、`data/iv-master.json` など4つのJSONがあることを確認します。解凍フォルダを丸ごと一段深く置かないでください。
4. **Settings → Pages → Build and deployment → Source** を **Deploy from a branch** にします。
5. **Branch：main / フォルダ：/(root)** を選び、**Save** を押します。別のブランチ名で作成した場合は、その名前を選びます。
6. Pages画面に表示される公開URLを開きます。公開準備の完了まで少し時間がかかる場合は、リポジトリの **Actions** で状態を確認します。

通常のプロジェクトURLは `https://あなたのユーザー名.github.io/リポジトリ名/` です。ユーザー名・リポジトリ名をアプリ内で設定し直す必要はありません。

`.nojekyll` はJekyll処理を省くための空ファイルです。Macで見えない場合は、Finderで **Command + Shift + .** を押すと表示できます。アップロードできなかった場合はGitHubの **Add file → Create new file** からファイル名 `.nojekyll` を作成してください。中身は空で構いません。

## 配布物

```text
index.html
manifest.json
service-worker.js
og.png
data/
  iv-master.json
  meal-master.json
  enteral-master.json
  ons-master.json
.nojekyll
README.md
```

`index.html` に画面と計算処理が入っています。`data` には初期製品マスタが入っています。Sites用の設定・サーバー・Git履歴・開発時の個人ファイルは含めていません。

## iPhoneで使う

Safariで公開URLを開き、共有メニューから **ホーム画面に追加** するとアプリ風に起動できます。最初はオンラインで開いてください。オフライン機能はブラウザの保存状態に依存し、必ず使えることを保証しません。

## 更新するとき

- 編集したマスタがある場合は、更新前に **マスタ管理 → JSON書出** で各カテゴリをバックアップしてください。
- 同じ公開先のファイルを差し替えて更新します。公開先やブラウザを変えると端末保存マスタは自動移行しません。必要なカテゴリをJSON読込で戻してください。
- 別リポジトリ間でマスタ・キャッシュが混ざらないよう、公開先ごとに分離しています。従来版から移行する際も、書き出したマスタを必要に応じて読み込んでください。
- 保存済みマスタは初期JSONより優先されます。新しい初期値へ戻す場合は、必要な編集内容を必ず書き出したうえで **初期データに戻す** を使ってください。
- ファイルを直接編集して再配布するときは、`service-worker.js` のバージョン（`v19`）も更新してください。

## 動かないとき

- ZIPのまま、またはPC上でHTMLをダブルクリックして使わず、GitHub PagesのHTTPS公開URLから開いてください。ローカルファイル表示ではJSONを読み込めない場合があります。
- 点滴名に「サンプル」が出る場合は `data` フォルダの場所を確認してください。Na試算は未確認データでは停止します。
- 404の場合は `index.html` の配置と、Pagesのブランチ・`/(root)` 指定を確認してください。
- 古い画面が出る場合は、公開処理の完了を確認してオンラインでページを再読み込みしてください。サイトデータの削除は保存マスタも消すため、最初の対処として行わないでください。

## 残っている前提

院内食マスタはまだサンプルです。「糖質」の既存表示・登録値の定義は変更していません。Na補正量は閉鎖系の理論試算で、処方推奨や実測の上昇保証ではありません。臨床利用前に院内の確認・承認を行ってください。

本配布版は計算回帰テスト、保存先・キャッシュ分離のテスト、リポジトリ形式のサブフォルダでの配信確認を行っています。利用者のGitHubアカウントへの実際の公開と実機iPhoneでの受入確認は未実施です。
